# مشاهده قیمت،نمودار و تحلیل تغییرات قیمت داده های مالی تنها با چند کلیک در ربات تلگرام
* مرحله اول انتخاب داده مالی موردنظر
* مرحله دوم انتخاب قیمت های داده مالی انتخاب شده
* مرحله سوم انتخاب نمودار یا تحلیل نمودار توسط هوش مصنوعی یا فعال سازی سیستم هشدار در صورت تغییر قیمت داده مالی موردنظر
